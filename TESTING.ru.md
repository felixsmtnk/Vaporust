# Как проверяется Vaporust

[English](TESTING.md) · **Русский**

## Автоматические тесты

Запускаются на каждой сборке в GitHub Actions (`cargo test`), а также тесты библиотеки Aurelia.

- **Разбор страниц Steam** на сохраненных примерах (`testdata/steam`, сняты без входа в аккаунт):
  профиль, группа, обсуждения, руководство, мод Мастерской, отзывы, кураторы, данные магазина,
  поиск площадки, выпуски GitHub. Плюс мусор и обрезанные страницы: разбор не должен падать.
- **Испорченные файлы Steam**: appmanifest, libraryfolders.vdf, localconfig.vdf, shortcuts.vdf.
  Vaporust не должен их переписывать, если не смог прочитать.
- **Копии сохранений**: недоступный или поврежденный файл останавливает восстановление до
  замены, а сбой посередине откатывает уже замененное.
- **Архив обновления**: мусор, нет exe, не тот формат, другая разрядность - старый exe не трогается.
- **Цены площадки** по правилам валют Steam (минимальная цена, шаг, комиссии).
- **Смена аккаунта**: ответы прошлого входа не попадают в новый.
- **Загрузки**: расчет места на диске, решение, продолжать ли после ошибки сети, конфликты
  временной папки.
- **Экспериментальные функции**: список действий, которые без переключателя не выполняются.

Не моделируются: настоящий обрыв связи посреди загрузки и выключение компьютера посреди
восстановления сохранений (на этот случай перед восстановлением делается страховочная копия).

## Еженедельная проверка страниц Steam

Раз в неделю GitHub Actions (`steam-pages.yml`) скачивает свежие публичные страницы Steam (без
входа) и запускает на них тесты разбора. Если Valve поменяла разметку и разбор сломался, сам
создается issue: ошибка находится раньше, чем ее заметят пользователи.

## Живые тесты

Помечены `#[ignore]` и запускаются вручную (`cargo test <имя> -- --ignored`): они ходят в сеть
Steam с сохраненным входом, только читают и ничего не публикуют. Загрузки проверяются только на
играх, которых нет в библиотеках.

## Ручная проверка

Каждое изменение проверяется в самой программе на двух компьютерах с Windows 10: обычный ПК
(NVIDIA) и старый ноутбук ThinkPad E330 (графика Intel). Что проверено мало - в README, раздел
«Что проверено».
